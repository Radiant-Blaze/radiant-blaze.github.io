# Agent project notes

`.agent/` is persistent context for future coding-agent sessions. Read `PROJECT.md` first, then read only the topic files relevant to the task:

- `ARCHITECTURE.md`: runtime and build architecture.
- `FILES.md`: important-file map.
- `ROUTES.md`: public URL contracts.
- `CONTENT.md`: Markdown, frontmatter, indexes, and converter.
- `COMPATIBILITY.md`: active fallback assets and historical backup boundary.
- `WORKFLOWS.md`: development and validation commands.
- `TESTING.md`: automated and browser checks.
- `DECISIONS.md`: migration guardrails.

These notes describe the current repository, but source code and configuration are authoritative if this documentation becomes stale. After reading `PROJECT.md`, consult only the relevant files before editing.

# Important file map

## Configuration

- `package.json` — npm commands and Astro/`js-yaml` dependencies. Edit scripts only with care because they define validation and publishing workflow.
- `package-lock.json` — locked dependency graph; generated by npm.
- `astro.config.mjs` — static Astro configuration and `sourceAssetsIntegration()` registration. Normally edit only for deliberate build changes.
- `src/content.config.ts` — collection loaders and schemas for posts, writeups, and events.

## Astro source

- `src/pages/index.astro` — home page.
- `src/pages/pages/blog.astro`, `ctf.astro`, `search.astro`, `archive.astro`, `post.astro`, `writeup.astro` — public shell pages.
- `src/pages/generated/posts/[...path].astro` — static post route.
- `src/pages/generated/writeups/[ctf]/[challenge].astro` — static writeup route.
- `src/pages/content/` — raw Markdown/JSON compatibility endpoints.
- `src/pages/sitemap.xml.ts` — Astro-owned sitemap endpoint.
- `src/pages/astro-article-order.json.ts` — ordered route metadata endpoint.
- `src/pages/404.astro` — not-found page.
- `src/layouts/ArticleShell.astro`, `QuestShell.astro` — shared page shells.
- `src/lib/article-data.ts` — ordered collection entries and public route path helpers.
- `src/lib/runtime-read-model.ts` — build-time read-model projection.
- `src/lib/home-data.ts`, `home-selection.ts`, `article-metadata.ts`, `listing-html.ts`, `source-json.ts`, `source-markdown.ts` — page data, selection, metadata, listing, and compatibility helpers.
- `src/lib/markdown.ts` — public Markdown rendering compatibility API; delegates to the new converter.
- `src/lib/markdown-converter/frontmatter.ts` — YAML frontmatter extraction.
- `src/lib/markdown-converter/html.ts` — escaping and math protection.
- `src/lib/markdown-converter/index.ts` — structured Markdown conversion.
- `src/components/` — not present in the current repository; do not assume component files exist.

## Content and tooling

- `content/posts/**/*.md` — authored posts.
- `content/ctfs/<event>/*.md` — authored writeups.
- `content/posts/index.json` — deterministic post order.
- `content/ctfs/index.json` — deterministic event order.
- `content/ctfs/<event>/ctf.json` — event metadata and challenge order.
- `content/site.json` — authored site metadata.
- `astro-tools/content-sync/` — discovery, ordering, validation, synchronization, and tests.
- `astro-tools/source-assets.mjs` — dev middleware and build-time static/compatibility asset copying.
- `astro-tools/test-*.mjs`, `check_*.mjs`, `compare_output.py` — focused tests and parity/projection checks.
- `compat/legacy-assets/js/blog.js`, `ctf.js`, `content.js` — active fallback modules; preserve their relative imports.
- `assets/js/` — active browser modules, including `astro-pages.js`, `astro-navigation.js`, `astro-controls.js`, `astro-query-model.js`, and `list-utils.js`.
- `backup/` — historical archive, not normal source.
- `.github/workflows/` — GitHub Pages deployment; installs dependencies, builds Astro, and uploads `dist/`.

No current application file should read generated legacy HTML or `.generated` manifests.

# Legendre Symbol (Easy Summary)

Problem:
In the previous challenge, we found square roots by checking every number from 0 to p-1.

Example:

for a in range(p):
    if (a * a) % p == x:
        print(a)

This works for small primes like p = 29, but for very large primes (1024-bit), it is too slow.

--------------------------------------------------

Solution:
Use the Legendre Symbol.

Instead of checking every number, perform ONE calculation:

    a^((p-1)/2) mod p

Python:

    pow(a, (p - 1) // 2, p)

This tells us whether a square root exists.

--------------------------------------------------

How to read the result:

Result = 1
→ Quadratic Residue (QR)
→ A square root EXISTS.

Result = p - 1
→ Quadratic Non-Residue (QNR)
→ No square root exists.
(Note: p-1 represents -1 in modular arithmetic.)

Result = 0
→ a is divisible by p.

--------------------------------------------------

Example:

p = 29

pow(6, 14, 29)
= 1

Therefore:
6 is a Quadratic Residue.

pow(18, 14, 29)
= 28 (= -1 mod 29)

Therefore:
18 is a Quadratic Non-Residue.

--------------------------------------------------

Finding the Square Root

The Legendre Symbol only tells us IF a square root exists.
It does NOT find the square root.

If the prime satisfies:

    p ≡ 3 (mod 4)

then we can directly compute the square root using:

    sqrt = a^((p+1)/4) mod p

Python:

    root = pow(a, (p + 1) // 4, p)

--------------------------------------------------

Cheat Sheet

Old Method:
Loop through every number
↓
Slow

New Method:
pow(a, (p - 1) // 2, p)

Result = 1
→ Quadratic Residue (QR)
→ Square root exists.

Result = p - 1
→ Quadratic Non-Residue (QNR)
→ No square root exists.

If p ≡ 3 (mod 4):

Square Root:
    pow(a, (p + 1) // 4, p)

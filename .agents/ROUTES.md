# Public routes

## Current Astro routes

- `/` — home.
- `/pages/blog.html`, `/pages/ctf.html`, `/pages/search.html`, `/pages/archive.html` — listing/search shells.
- `/pages/post.html`, `/pages/writeup.html` — compatibility/query shells.
- `/generated/posts/...` — Astro-generated post routes.
- `/generated/writeups/{event}/...` — Astro-generated writeup routes.
- `/content/posts/index.json`, `/content/ctfs/index.json`, `/content/ctfs/{event}/ctf.json` — compatibility metadata endpoints.
- `/content/.../*.md` — raw Markdown compatibility endpoints.
- `/content/runtime-read-model.json` — generated read-model endpoint.
- `/astro-article-order.json` — ordered route metadata.
- `/sitemap.xml` — Astro-generated sitemap.
- `/404.html` — Astro 404 output.

## Compatibility URLs

`/generated/posts/...` and `/generated/writeups/...` are stable public contracts. They are generated by Astro routes even though their names reflect the former output layout.

`/legacy/assets/js/blog.js`, `/legacy/assets/js/ctf.js`, `/legacy/assets/js/content.js`, and `/legacy/assets/js/list-utils.js` are preserved compatibility asset URLs. The first three source from `compat/legacy-assets/js/`; `list-utils.js` sources from `public/assets/js/`.

## Static assets

`/assets/...`, `/favicon.svg`, `/og-image.png`, and `/robots.txt` are served from Astro's public directory (`public/assets/`, `public/favicon.svg`, `public/og-image.png`, `public/robots.txt`): Astro serves them during development and copies them into `dist/` at build time. The root `.nojekyll` is copied into `dist/` by `astro-tools/source-assets.mjs`. `/sitemap.xml` is generated by Astro, not checked in as a source file.

Do not rename public generated or legacy compatibility paths without an explicit migration plan.

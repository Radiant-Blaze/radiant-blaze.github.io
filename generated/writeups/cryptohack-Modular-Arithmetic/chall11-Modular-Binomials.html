The Capture

The challenge gives us an RSA modulus:

N = p · q

along with two ciphertext equations:

c1 = (2 · p + 3 · q)^e1 mod N
c2 = (5 · p + 7 · q)^e2 mod N

The goal is to recover the two prime factors p and q.

At first glance, this looks like a difficult RSA problem because p and q are hidden inside modular exponentiation.

However, the expressions contain a useful weakness.

The two plaintext expressions are:

2p + 3q
5p + 7q

and because:

N = p · q

we can exploit their behavior modulo the two unknown factors.

The Mistake

Consider the first expression:

2p + 3q

Modulo p:

2p + 3q ≡ 3q (mod p)

Modulo q:

2p + 3q ≡ 2p (mod q)

Likewise, the second expression:

5p + 7q

becomes:

5p + 7q ≡ 7q (mod p)

and:

5p + 7q ≡ 5p (mod q)

This means that after choosing suitable exponent multiples, we can make the unknown powers disappear using Euler's theorem.

The key is to use the least common multiple of the two exponents:

L = lcm(e1, e2)

Then define:

a = L // e1
b = L // e2

so that:

e1 · a = L
e2 · b = L

Therefore:

c1^a ≡ (2p + 3q)^L mod N
c2^b ≡ (5p + 7q)^L mod N

Recovery

We now compensate for the coefficients in the two expressions.

Raise 7 and 3 to the common exponent L:

x = pow(7, L, N) * pow(c1, a, N)
y = pow(3, L, N) * pow(c2, b, N)

The important observation is what happens modulo each prime.

Modulo p, the first expression behaves as:

(2p + 3q)^L ≡ (3q)^L

Multiplying by 7^L gives:

x ≡ (21q)^L (mod p)

For the second expression:

(5p + 7q)^L ≡ (7q)^L

Multiplying by 3^L gives:

y ≡ (21q)^L (mod p)

Therefore:

x ≡ y (mod p)

which means:

p | (x - y)

So the greatest common divisor reveals the hidden prime:

p = gcd(N, x - y)

This is the critical step of the attack.

If the result is neither 1 nor N, we have successfully recovered a factor of N.

The other prime is then simply:

q = N // p

The attack does not factor N by brute force.

Instead, it constructs two values that are guaranteed to be equal modulo one of the secret primes. The difference therefore contains that prime as a factor.

The Capture

In the previous challenge, we found quadratic residues by checking every possible value from 0 to p - 1.

That approach works for small primes, but becomes impractical when p is a very large prime.

The Legendre Symbol gives us a much faster way to determine whether a number is a quadratic residue.

For a prime p, we calculate:

a^((p-1)/2) mod p

In Python:

pow(a, (p - 1) // 2, p)

The result tells us whether a square root exists.

The Mistake

The result can be interpreted as follows:

1
→ Quadratic Residue
→ A square root exists

p - 1
→ Quadratic Non-Residue
→ No square root exists

0
→ a is divisible by p

The value p - 1 represents -1 modulo p.

For example, with p = 29:

pow(6, 14, 29) = 1

Therefore, 6 is a quadratic residue.

For a quadratic non-residue:

pow(18, 14, 29) = 28

Since 28 = -1 mod 29, 18 is not a quadratic residue.

p ≡ 3 mod 4

For primes with this property, a square root of a can be calculated as:

a^((p+1)/4) mod p

In Python:

root1 = pow(x, (p + 1) // 4, p)
root2 = p - root1

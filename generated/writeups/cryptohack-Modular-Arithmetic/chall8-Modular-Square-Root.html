MODULAR SQUARE ROOT

The Capture

The goal of this challenge is to find:

sqrt(x) mod p

There are two main cases when finding modular square roots.

Case 1: p ≡ 3 (mod 4)

If the prime satisfies:

p ≡ 3 (mod 4)

we can use the simple formula:

root = pow(x, (p + 1) // 4, p)

Case 2: p ≡ 1 (mod 4)

If:

p ≡ 1 (mod 4)

we need a more general algorithm such as Tonelli-Shanks.

The Mistake

Tonelli-Shanks works only with prime moduli.

It is commonly used to find square roots of quadratic residues modulo a prime.

It is useful in cryptography, including:

  • Elliptic Curve Cryptography (ECC)
  • Finding coordinates on elliptic curves

The first step is to check whether a is a quadratic residue using the Legendre Symbol:

pow(a, (p - 1) // 2, p)

If the result is 1, then a square root exists.

Tonelli-Shanks Solution

The following implementation handles both the easy p ≡ 3 (mod 4) case and the general p ≡ 1 (mod 4) case.

def Tonelli_Shanks(a, p):
    """
    Returns:
       1  -> Quadratic Residue
      -1  -> Quadratic Non-Residue
       0  -> a is divisible by p
    """
    ls = pow(a, (p - 1) // 2, p)
    return -1 if ls == p - 1 else ls


def square_root(a, p):
    """Finds sqrt(a) mod p using the Tonelli-Shanks algorithm."""

    # No square root exists
    if Tonelli_Shanks(a, p) != 1:
        return None

    # Easy cases
    if a == 0:
        return 0

    if p == 2:
        return 0

    # Shortcut when p ≡ 3 (mod 4)
    if p % 4 == 3:
        return pow(a, (p + 1) // 4, p)

    # Write p - 1 = q * 2^s
    q = p - 1
    s = 0

    while q % 2 == 0:
        q //= 2
        s += 1

    # Find a quadratic non-residue z
    z = 2

    while Tonelli_Shanks(z, p) != -1:
        z += 1

    # Initialize variables
    m = s
    c = pow(z, q, p)
    t = pow(a, q, p)
    r = pow(a, (q + 1) // 2, p)

    while t != 1:

        i = 0
        temp = t

        while temp != 1:
            temp = pow(temp, 2, p)
            i += 1

        b = pow(c, 1 << (m - i - 1), p)

        r = (r * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return r


# ------------------------
# Find the square roots
# ------------------------

root1 = square_root(a, p)

if root1 is None:
    print("No square root exists.")
else:
    root2 = p - root1

    print("Root 1 :", root1)
    print("Root 2 :", root2)
    print("Smaller Root :", min(root1, root2))
    print("Larger Root :", max(root1, root2))

Once one root is found, the other root is:

root2 = p - root1

because:

(-root1)² ≡ root1² (mod p)

The challenge asks for the larger root.
